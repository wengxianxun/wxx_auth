# 2026-10-10

## wxx_auth 插件：第三方登录整合（v1）

将 `wxx_auth` 从空壳 Flutter 插件改造为「第三方登录整合插件」。

### 架构决策
- 状态管理用 **GetX**（`get ^4.7.2`）。之前我误把抽象类命名为 `AuthProvider`，用户明确说「不要用 provider，用 getx」——指的是别混用 `provider` 包。已重命名为 `AuthMethod` 抽象类（可扩展扩展点），具体实现 `GoogleAuth` / `AppleAuth`。
- 范围：**仅 iOS / Android**（用户要求去掉 Web）。

### 关键 API 修正（已读包源码确认）
- `google_sign_in ^7.2.0`：`GoogleSignIn.instance.initialize()` 必须且只调用一次；`authenticate()` 返回非空 `GoogleSignInAccount`，**取消时抛 `GoogleSignInException`**（不返回 null）；`account.authentication` 是**同步** getter，且 `GoogleSignInAuthentication` 只有 `idToken`（无 accessToken，accessToken 要走 authorization client）；`attemptLightweightAuthentication()` 返回可空 Future。
- `sign_in_with_apple ^8.2.0`：`SignInWithAppleButton` 变为**纯展示组件**（无 loading/scopes/webAuthenticationOptions，style 是枚举 black/white/whiteOutlined），登录逻辑由 `SignInWithApple.getAppleIDCredential` 完成；`AppleIDAuthorizationScopes` 是枚举。

### 文件
- `lib/wxx_auth.dart`（门面：init/getPlatformVersion 静态）、`src/core/auth_method.dart`、`src/providers/{google,apple}_auth.dart`、`src/config/wxx_auth_config.dart`、`src/controller/wxx_auth_controller.dart`、`src/ui/{wxx_auth_button,wxx_auth_view}.dart`
- `pubspec.yaml` 加了 google_sign_in/sign_in_with_apple/flutter_svg；example 加了 get/sign_in_with_apple。

### 校验
`flutter analyze` 通过（仅剩 `flutter_taptap` path 依赖的预存警告），`flutter test` 单元用例通过。宿主 App 仍需各自配置 Google/Apple 原生参数（README 已写）。
