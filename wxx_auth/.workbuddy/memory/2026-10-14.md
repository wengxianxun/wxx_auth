## 后端 API 接入 example（wxx_auth 后台 = SpeedPHP，本地 http://192.168.31.76/nboxphp/index.php）
- 新增 `example/lib/backend/`：
  - `api_client.dart`：http 封装（baseUrl 常量 `kBackendBaseUrl`）+ Bearer token 注入 + 错误解析（`ApiException`）。
  - `models.dart`：`BackendUser` / `SignInResult` / `ProfileProvider` / `ProfileResult`（按后端 JSON 字段映射）。
  - `auth_repository.dart`：按 provider 提取凭证 → `POST /api/auth/signin` 换 JWT；`GET /api/user/profile`。
  - `backend_controller.dart`：GetX 控制器，监听 `WxxAuth.controller.user` 自动调后端换 JWT，管理后端状态。
- `main.dart`：登录成功后自动向后端校验换 JWT，展示后端 UUID / is_new / 邮箱 / 名称；新增「获取用户信息 / 已绑平台」按钮展示多平台绑定。
- 凭证映射：Google→idToken；Apple→identityToken（+ raw 里的 givenName/familyName 作为 fullName，仅首次）；TapTap→accessToken + openId（+ unionId + macKey）。
- 平台配置：`example/pubspec.yaml` 加 `http: ^1.4.0`；`AndroidManifest.xml` 加 `android:usesCleartextTraffic="true"`（明文 http）；`Info.plist` 加 `NSAppTransportSecurity` 例外 `192.168.31.76`（调试用，生产应改 HTTPS）。
- 校验：`flutter analyze example` 无错。
- 注意：后端校验是安全闸门，token 仅存内存（生产建议 flutter_secure_storage）。

## API 调用日志
- `api_client.dart` 加 `kEnableApiLog = true`（`_logApi` 用 `print('[API] …')`）。
- `postJson`/`getJson` 打印：method+URL、headers（`Authorization` 脱敏只留前 16 位）、请求体（`_pretty` 缩进 JSON）。
- `_handle` 打印：状态码（错误标 (ERROR)）、响应体（缩进 JSON）。
- 覆盖所有后端请求（signin/profile/ping）。生产可设 `kEnableApiLog=false`。
- `auth_repository.dart` 额外打印解析后的接口结果：`[RESULT] signin(...)`（uuid/isNew/email/name）与 `[RESULT] profile(...)`（uuid/email/name/providers 列表）。

## 优化 API 使用（依据后台使用文档）
- 重大修复：TapTap 凭证提取 bug。原生层此前把 SDK 的 `AccessToken` 对象整体序列化
  （Android `toString()` / iOS `toJsonString()`），发出的是 `AccessToken(kid=1/..., macKey=...)` 调试串，
  而非真实 token——正是后台文档 §7 警告的#1 坑。现改为只提取真实 `kid` 与 `macKey`。
  - `flutter_taptap/android/.../FlutterTaptapPlugin.kt`：login + getCurrentUser 改用 `at?.kid` / `at?.macKey`，map 新增 `macKey`。
  - `flutter_taptap/ios/Classes/FlutterTaptapPlugin.swift`：解析 `toJsonString()` 取 `kid` / `macKey`，map 新增 `macKey`。
  - `flutter_taptap/lib/model/flutter_taptap_user.dart`：新增 `macKey` 字段（fromMap/toMap/toString）。
- `example/lib/backend/auth_repository.dart`：TapTap 分支显式取 `user.accessToken`(kid)+`raw['macKey']`，缺失则抛 `AuthException`（missing_token/missing_mac_key）。
- `backend_controller.dart`：新增 `_describeApiError()`，把后台错误码（invalid_request/unsupported_provider/verify_error/invalid_credentials/server_error/unauthorized/invalid_token/user_not_found_or_disabled）翻译成中文提示；catch 增加 `AuthException`。
- 接入 `/api/auth/ping` 自检：`api_client.ping()` / `auth_repository.ping()` / `models.PingResult` / `backend_controller.ping()`，example `main.dart` 后端面板顶部新增「检查后端连通性 (ping)」按钮 + 结果展示。
- 校验：example `flutter analyze` 无错；flutter_taptap `flutter analyze lib` 仅 3 条 pre-existing unnecessary_import info。
